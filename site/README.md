# Parallel Tube Decoding project page

This folder is a self-contained static website for **Locate Anything in Videos: Rethinking Efficient Generative Spatio-Temporal Video Grounding**.

## Preview locally

From the repository root:

```bash
python -m http.server 8000 --directory site
```

Then open `http://localhost:8000`.

## Publish

The folder can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. No build step or external dependency is required.

Before the paper release, replace the disabled **Paper · soon** chip in `index.html` with the final paper URL and update the BibTeX entry if the venue or arXiv identifier changes.
